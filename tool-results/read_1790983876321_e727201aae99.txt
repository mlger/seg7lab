     1→# 7-Segment Display Logic Simulator — Shared Worklog
     2→
     3→Project: Interactive 7-segment decoder design & simulation lab (Next.js 16, App Router, TypeScript, Tailwind 4, shadcn/ui, Prisma/SQLite, Zustand).
     4→
     5→Architecture decisions:
     6→- Single source of truth: Zustand store holds inputBits, currentInput, truthTable (all segment outputs incl. X/don't-care), display settings, cover exclusions. K-maps, Boolean expressions (SOP/POS/canonical), logic circuit, and the 7-seg display are all DERIVED from the truth table via a pure logic engine in `src/logic/`.
     7→- Real Quine-McCluskey minimizer with don't-care handling + exact cover (essential primes + branch & bound) — NO hard-coded expressions.
     8→- Input variable naming: 4-bit = D C B A (D = MSB, weight 8); 5-bit = E D C B A (E = MSB, weight 16). Segment outputs named A-G + DP (standard).
     9→- Only route visible to user: `/` (src/app/page.tsx). Backend REST at /api/projects (Prisma SQLite) with localStorage fallback for offline/demo mode.
